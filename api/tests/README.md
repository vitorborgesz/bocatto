# tests/

Pasta reservada para os **testes automatizados** da API.

Ainda não há testes nem ferramenta de testes declarada no `requirements.txt`.
A escolha da ferramenta (por exemplo, pytest) e a estratégia de banco para os testes
serão definidas pela equipe e registradas em `docs/arquitetura.md`.

Enquanto isso, a API pode ser testada manualmente pelo Swagger
(<http://localhost:8000/docs>) ou pela collection do Postman em `postman/`.
