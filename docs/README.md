# Documentação do Bocatto

Esta pasta reúne a documentação técnica e os materiais de apoio do projeto.

| Documento | Conteúdo |
| --- | --- |
| [arquitetura.md](arquitetura.md) | Organização da aplicação: camadas, comunicação entre front e API, decisões técnicas |
| [modelagem.md](modelagem.md) | Banco de dados: entidades, relacionamentos, regras e decisões de modelagem |

## Convenções

- Diagramas (ER, arquitetura, fluxos) ficam nesta pasta, de preferência em formato
  versionável como texto (Mermaid ou PlantUML), acompanhados de uma imagem exportada
  quando for útil.
- Toda decisão relevante é registrada com **data**, **decisão** e **motivo**, para que o
  histórico do projeto possa ser entendido depois.
- O que ainda não foi decidido aparece marcado como **A definir**.
